# ScienceToStartup research package

Complete research package frozen before archival publication. Check the release record for current DOI registration and publication status. Reserved version DOI (not registered): 10.5281/zenodo.24249277.

Start with executive-brief.html for the short briefing, report.html for the full offline report, then evidence.html for entity dossiers, a recorded-scope comparison, assertions, source metadata and review receipts. corrections.json contains accepted correction metadata; the appendix retains superseded IDs as metadata-only links to approved replacements. Evidence links resolve within the extracted edition without the live site. Citation files reflect archive status. JSON, CSV and SQLite are equivalent privacy-filtered projection 1.2.0, not replacements for canonical dataset 2.5.0. Full source text and personal contacts are excluded. CC BY 4.0 covers owned research/text; third-party evidence retains its rights. The DejaVu fonts and Noto Sans SC derived CJK subset are excluded from the project CC BY 4.0 and MIT licenses. Their unmodified upstream terms are in DejaVu-LICENSE.txt and CJK-OFL.txt; DejaVu-PROVENANCE.json and CJK-PROVENANCE.json record source hashes and the subset recipe.

Run `python3 reproduce.py --write-tables reproduced` inside this extracted package to verify MANIFEST.json, compare all three exports, validate the graph and reproduce coverage and approved-assertion tables. This needs only Python's standard library and no network. Schemas, methods and a source manifest are included. Versioned audit calculations and exact admitted frozen receipts are checked when supplied; this does not revalidate private withheld wording or raw third-party sources against a mutable current input. source-manifestations.json and SOURCE-MANIFESTATIONS.md explain how to reproduce repaired evidence coordinates from independently obtained matching source bytes; source bodies are not redistributed. The PDF is accepted only when its receipt binds this exact context. No remote publication occurs during the build.
