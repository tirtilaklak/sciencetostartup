# November 19 usability refinement

This round adapts common interaction patterns from five reference sites. The implementation uses this project's existing Python, CSS and JavaScript. No third-party website source, templates, assets or research data were copied. Public repositories were inspected where available; none supplied a suitable licensed website template for these changes.

| Reference | Applied pattern |
| --- | --- |
| [Epoch AI](https://epoch.ai/) | Visible evidence dates and links to company record sections. Historical figures retain their dates and qualifications. |
| [Hugging Face datasets](https://huggingface.co/datasets) | Grouped downloads, distinct report and graph release identifiers, and nearby citation, licensing and checksum links. |
| [Artificial Analysis](https://artificialanalysis.ai/methodology) | Readable navigation, clear choices and concise labels. Correct portrait sizing reduces the selected image payload where the smaller source fits. |
| [Elicit](https://support.elicit.com/en/articles/14759154-systematic-reviews-in-elicit) | Removable paper filters and native disclosures for record identifiers and review guidance. All paper records remain in the initial HTML. |
| [AI Training Index](https://aitrainingindex.com/platforms) | Immediately available work filters, explicit recorded pay and geographic conditions, and result counts that distinguish listings from networks. |

The underlying datasets, source bindings, review statuses, financial qualifications, pay caveats and archived publication files are unchanged by this round. Source retrieval remains distinct from claim approval, and historical records remain distinct from current verification.
