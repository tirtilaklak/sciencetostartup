## Product decision

[ScienceToStartup](https://sciencetostartup.com/) serves AI-data company research, paid AI training work and the papers/datasets behind those markets. Its useful distinction is inspectable evidence. Improve the initial decision and the path to the source. Broad science-commercialization positioning would imply coverage the current product does not provide.

Keep the static Python build and native HTML. A framework migration, new editorial database, account system or AI verification API would not resolve the demonstrated pay-scope, geography, review-history and navigation defects. A source link is necessary provenance; it does not establish that the attached sentence follows from the source.

In this review, **observed** means inspected content, a bounded response or a public interaction. **Provider claims** describe a publisher's methods/features without certifying every result. **Proposed** means a change that still requires implementation and validation. No site is certified bug-free, debt-free, permanently available or universally fastest.

## Site findings and proposed changes

The original audit distinguished 53 directory profiles from the unchanged 39-company historical dataset. All 135 work records were structurally inspected across 945 field slots; 376 sourced fields lacked a precise field-review date. Those nulls must not be replaced with build dates. Source-reference integrity does not establish semantic support for every sentence.

Source-content review proposed precise corrections: testimonial geography is not eligibility; a network average is not individual pay; project duration is not a stipend payment period; board absence is not a specific closure. These were research candidates requiring the normal scoped review; this document does not claim they were published.

Search observations included exact names losing to incidental text, missing aliases, wrong initial ArrowUp behavior and an optional component without a deadline. Proposed repairs prioritize identities, truthful totals, more-results navigation and native fallback. Preserve Unicode, C++/C#, composition input and unrelated URL state.

The paper index contained 248 works and 208 versions: 377 approved records and 79 candidates. Fifty-seven candidate versions had approved work parents. Proposed grouping must keep all 456 records once in initial HTML and preserve each record's status. Version disclosures belong in nonindexed sibling wrappers; a hidden approved row must not hide a matching candidate version. Context parents are labelled and excluded from match totals.

Use readable controls/titles and supporting metadata, native disclosures and complete source links. Long source/version names should survive titles and sharing metadata. Existing approved scoped statements can replace mechanical relationship grammar without changing graph assertions or digests. ## SEO/AEO and a 30-day distribution cadence

Use ordinary [AI-search fundamentals](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide): useful text, provenance, internal links and truthful metadata. [Titles need descriptive distinctions](https://developers.google.com/search/docs/appearance/title-link), not an arbitrary 59-character truncation. [Dataset identifiers](https://developers.google.com/search/docs/appearance/structured-data/dataset) and related publication citations describe different objects. A report DOI does not identify every dataset mentioned. Do not add [JobPosting](https://developers.google.com/search/docs/appearance/structured-data/job-posting) globally to mixed programs and historical routes. Sitemap access and schema validity do not prove indexing or AI citations.

Make the owned site the permanent destination. Proposed Daily [RSS](https://www.rssboard.org/rss-specification) and [JSON Feed](https://www.jsonfeed.org/version/1.1/) should use the same validated snapshots as HTML/search, one entry per dated edition, with permanent item anchors. Keep edition/correction streams separate. Selection/source/compilation dates do not establish first public publication; omit optional timestamps where unknown. No email form without a real delivery/unsubscribe system.

The recurring distribution budget is roughly 2.5–3 hours weekly after the setup/QA pass; source reading and research approval are additional. Hold unsupported editions instead of padding a quota. GitHub is the reproducibility entry; an actual Hugging Face mirror needs a card explaining grain, review states, limits and licensing. No posts, accounts, subscriptions or schedules were created by this research.

Keep existing measurement. Feed polls are not subscribers, views are not applications, and an internal example is not external adoption. The [Cloudflare FAQ](https://developers.cloudflare.com/web-analytics/faq/) documents limits including unsupported custom events/UTM tracking. No private analytics or traffic forecast is asserted here.
