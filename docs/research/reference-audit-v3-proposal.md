# Reference v3: genuine-input disposition-stratified source-quality holdout

Implementation proposal, pending independent code review and explicit adoption.
No actual current-case SUT, scientific adjudication, receipt, admission or SCI
change is supplied. Tests use invented in-memory fixtures only.

The coordinator selected this design before fresh gold: the SUT is the unchanged
`research_graph.public_graph` function applied to the complete genuine current
input graph. Approved and actually retained candidate/rejected scientific drafts
are eligible inputs; historical records are excluded. Do not append evaluation-
only drafts, create false hypotheses, change statuses or invent approvals to
obtain a desired panel. A supported but prudently withheld draft is a false
negative under this endpoint. It is not procedurally unapproved gold-negative.

The endpoint measures exact source-supported assertion retention on the sampled
actual inputs. It does not measure discovery, extraction recall beyond the panel,
or a new source verifier. Both the assertion ID and exact scoped scientific
content must survive the public output for an observed positive. Scientific
approval records and audit source-truth adjudications remain distinct.

Before selection, source/domain mixing or a SUT run, independently review the
neutral frame and the exposure registry against **all** old250/226 cases and
all62 touched findings, including qualification/citation successors and semantic
equivalents. New IDs, sources, qualifiers or aliases do not establish freshness.
The registry binds exact original scope-artifact bytes and an actual independent
semantic-review artifact. Its three named SHA fields, nonempty lists and an
invented review string cannot prove completeness. The actual registrar/admission
review must authenticate the original bytes and inspect that semantic review.
No function creates or accepts its own trust admission.

Neutral curation must cover every nonhistorical assertion of the real input
graph and preserve every excluded row and reason. It classifies substantive
scope/primary-source availability/equivalence, never new supported/unsupported
gold. Pure title, metadata, version/family identity and similar easy fillers are
excluded by actual reviewed curation; the code additionally bans identity-only
predicates. Unsupported genuine drafts cannot be excluded merely because their
source-quality prediction is inconvenient. Keep absence/ambiguous primary-source
scope visible and do not silently manufacture source pins.

Freeze complete genuine input bytes, adopted code/policy, complete neutral frame,
exclusions, source packet, domain/predicate mix and seed. Order each actual
disposition stratum by SHA256(seed + newline + original assertion ID). Take
`min(100, available genuine withheld)` and fill the remainder to200 from actual
output records. Freeze those resulting quotas and exact membership before the
SUT run and any fresh gold. Do not change the design after scores. An all-output
panel leaves rejection/FN behavior untested and remains held. Insufficient genuine
cases remain incomplete; no invented negatives or metadata fillers are permitted.

Run/seal the actual unchanged projection on that exact full input. Two new
independent source-only truth invocations then read exact captured cited primary
sources without status, existing review history, predictions, old keys, prior
rationales or each other's conclusions. Freeze observations before decisions.
Their audit decisions are supported/unsupported/unknown and independently assess
critical attribution if accepted. Disagreement requires a retained independent
source-first tie decision. Negative source truth never approves its false
hypothesis for SCI. Unknown remains in the same selected200 and holds completion.

Raw TP/FP/FN/TN, source abstentions and exact denominators are recomputed, with
unchanged floors200,98% precision,95% recall and zero critical false attribution.
These are unweighted metrics for the disposition-enriched finite panel, not
population estimates. Do not weight or adjust a failed panel into a pass. Numeric
success is separate from integrity, actual execution, adoption and completion.

`execute_reference_projection` returns actual output/run bytes without writing
files or truth. `build_reference_frame` and `select_reference_panel` build the
neutral fixed panel. `sampled_bindings` commits scientific content, actual status
and output decision, exact original source records/capture times, entity identity
and any actual original review records. Empty candidate review history is valid;
no factual PASS is invented to make a negative case admissible.

`validate_private_reference_v3` requires independently retained closed artifact
pins and every original payload, including input, output, execution, neutral
curation, old exposure scopes, semantic review, source-only packet/observations,
actual truth entries and all distinct sampled raw primary responses. It checks
original entry pointers, exact decisions and provenance. A deterministic replay
authenticates the earlier output; it is not a newly fabricated pre-gold run. Its
receipt preserves all holds and cannot admit itself.

`validate_public_reference_v3` requires exact audit/receipt bytes, complete current
input graph and a separately reviewed caller-trusted admission. It checks current
sampled scientific/source/identity/status/output bindings. Unrelated graph
additions and additional review links are allowed; original review records remain
exact and attached. True sampled changes hold applicability. The actual SUT and
reader/schema/dispatch capsule are pinned. Candidate wording/raw source bodies
are absent from the public audit allowlist.

A filtered public output omits withheld wording and cannot reconstruct mutable
withheld bindings. A standalone archive verifies the independently admitted
**frozen** receipt/context and must explicitly identify that scope. It cannot
claim the live-current-input validation this reader performs. Root packaging must
implement and bind that distinction; there is no private-cache fallback here.

The proposed dispatcher adds v3 explicitly. Legacy and v2 readers stay unchanged;
unknown versions never fall back. Central gate/build/archive integration is still
the coordinator's reviewed change. Actual method/frame/adoption review must
precede registrar freeze; actual source/execution/completion admission follows
execution and cannot be supplied by fixture tests.

Verification:15 v3 fixture controls include genuine unchanged projection execution
on synthetic inputs, supported withheld FN, unsupported emitted FP, preserved
Unknown, critical failure despite numeric floors, exposure/seed/filler rejection,
unrelated additions versus sampled changes, source chronology, missing trust,
unchanged floors, full-input requirement, complete scope disclosures, original
artifact/source authentication, exact original truth projection tampering and
tampered output bytes. No actual research files or accepted admissions are made.
