# Reference v4 metadata projection correction

This is a validator/serialization correction after the first actual outcome
opening, not a new scientific method, SUT, sample, truth decision or score.
The original failed validation, its original code and every frozen input,
prediction, judgment and timestamp remain retained. No passing admission is
created by this document or its tests.

The frozen private exposure registry carries six scientific exposure fields and
eight known provenance annotations. The strict public v4 schema allows only the
six scientific fields. The old private reader required literal equality with
the complete private object, making an authentic annotated original incompatible
with its own public schema.

`public_exposure_registry` projects exactly the existing six schema fields. It
rejects missing scientific fields and unknown extra fields, omitting only eight
named provenance annotations. The private reader still authenticates every
original byte, binds the complete private object through the population review,
rebuilds the frame using the complete original, and compares the exact public
projection. Changes to any scientific exposure field remain failures. Private
metadata is never republished merely to satisfy a validator.

No endpoint, eligibility rule, scientific unit, exclusion set, sampling seed,
fixed membership, prediction, truth, threshold, chronology guard or computation
changes. The production SUT remains `research_graph.public_graph`. The schema
and prior readers remain unchanged. Git preserves the original v4 reader and
the original validation receipt pins its exact code.

Integration requires separate code review and exact replay of the retained
actual artifacts. That replay must retain the first outcome-opening/scoring
times and prove identical method, frame, membership, bindings, scientific truth
and metrics. A later faithful source-run metadata adapter must be disclosed
separately, preserve every scientific entry, and grant no earlier read credit.
Independent actual admission is still required afterward. Synthetic regression
tests verify serialization/authentication behavior only; they are not research
performance or admission evidence.
